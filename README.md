# Feelstone — лендинг feel-stone.ru

Одностраничный сайт бренда Feelstone: заметные украшения из Испании, трансформеры со сменными шарами. Заказы — через Telegram и MAX, корзины на сайте нет.

## Что где лежит

```
index.html                 страница: тексты и разметка
assets/css/style.css       оформление (цвета, шрифты, сетка)
assets/js/picker.js        работа блока «Подберите цвет шара»
assets/js/picker-data.js   цвета шаров и картинки для подбора
assets/img/                фотографии (формат WebP)
assets/img/picker/         шары для подбора: наложения на браслет и кольцо, кружки палитры
assets/video/              видео распаковки
CHANGELOG.md               что менялось в каждой версии
```

## Как поменять типичные вещи

- **Текст** — в `index.html`, найти фразу поиском и заменить.
- **Фото** — положить новый файл в `assets/img/` с тем же именем (лучше WebP, ширина до 1200 px).
- **Реквизиты продавца** — в `index.html`, блок `<footer class="foot">`.
- **Ссылки на Telegram и MAX** — в `index.html`: `t.me/feelstone_msk` и `max.ru/...`.

## Как посмотреть сайт у себя

Открыть `index.html` двойным щелчком в браузере.

## Версии

- Каждое изменение сохраняется коммитом с понятной подписью.
- Готовые к показу или выкладке состояния отмечаются метками: `v1.0-review`, `v1.0`, `v1.1` и т. д.
- Что поменялось — записывается в `CHANGELOG.md`.

## Выкладка (план)

- `dev.feel-stone.ru` — тестовый адрес, сюда выкладывается каждая правка.
- `feel-stone.ru` — основной сайт, сюда только версии с меткой `vX.Y`.
- Автоматическая выкладка по SFTP через GitHub Actions — настроим, когда будут доступы к хостингу.
- Перед первой выкладкой — полная резервная копия текущего сайта на Битриксе.
