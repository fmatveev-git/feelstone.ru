# Feelstone — лендинг feelstone.ru

Одностраничный сайт бренда Feelstone: заметные украшения из Испании, трансформеры со сменными шарами. Заказы — через Telegram и MAX, корзины на сайте нет.

## Что где лежит

```
index.html                 страница: тексты и разметка
assets/css/style.css       оформление (цвета, шрифты, сетка)
assets/js/picker.js        работа блока «Подберите цвет шара»
assets/js/picker-data.js   цвета шаров и картинки для подбора
assets/img/                фотографии (формат WebP)
assets/img/picker/         шары для подбора: наложения на браслет и кольцо, кружки палитры
CHANGELOG.md               что менялось в каждой версии
```

## Как поменять типичные вещи

- **Текст** — в `index.html`, найти фразу поиском и заменить.
- **Фото** — положить новый файл в `assets/img/` с тем же именем (WebP, ширина до 1200 px, вес до 200 КБ). Если имя новое — поменять его в `index.html` и удалить старый файл, если он больше нигде не используется.
- **Шары в подборе** — в `assets/js/picker-data.js`: там же описано, как добавить цвет.
- **Реквизиты продавца** — в `index.html`, блок `<footer class="foot">`.
- **Ссылки на Telegram и MAX** — в `index.html`: `t.me/feelstone_msk` и `max.ru/...`.

## Как посмотреть сайт у себя

Открыть `index.html` двойным щелчком в браузере.

## Версии

- Каждое изменение сохраняется коммитом с понятной подписью.
- Готовые к показу или выкладке состояния отмечаются метками: `v1.0-review`, `v1.1`, `v1.2` и т. д.
- **v1.2 — базовая версия** после технической уборки. Дальше мелкие правки — v1.2.1, v1.2.2…, заметные изменения — v1.3.
- Перед крупной правкой стоит сравнить страницу с базовой версией на телефоне и компьютере.
- Что поменялось — записывается в `CHANGELOG.md`.

## Выкладка

- Сайт публикуется через GitHub Pages из ветки `main` на адрес **feelstone.ru**.
- Любое изменение в `main` попадает на сайт автоматически примерно за минуту.
- Файл `CNAME` хранит адрес сайта — не удалять и не переименовывать.
- Файл `.nojekyll` отключает обработку GitHub, чтобы файлы отдавались как есть.
- DNS домена — в личном кабинете reg.ru: четыре A-записи на серверы GitHub Pages и CNAME `www` → `fmatveev-git.github.io`.
